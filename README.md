# COLD AI — голосовой помощник «Колд»

Android-приложение (Kotlin, Jetpack Compose, Room, Gemini API). Язык интерфейса: русский и украинский.

> **Статус проверки:** проект написан, но **не собирался** — в среде, где он создавался, не было доступа к сети и Android SDK. Первая сборка в GitHub Actions может показать ошибки компиляции. Если так, скопируйте текст ошибки из лога и передайте его — исправим.

## Что умеет
- Чат с Gemini (текст и голос), индикатор загрузки, отмена запроса, понятные ошибки (сеть, лимит, ключ, модель).
- Распознавание речи (`SpeechRecognizer`) по кнопке микрофона, озвучивание (`TextToSpeech`), выбор голоса, скорости и высоты.
- Команды без ИИ: открыть приложение / сайт / системные настройки, время и дата, управление музыкой (пауза, играй, следующий, предыдущий).
- Звонок и SMS — **только после подтверждения** и выдачи разрешений. Контакты — только с разрешением.
- Память (Room): история чатов, «Запомни, …», просмотр, удаление, очистка; историю можно отключить.
- Светлая и тёмная темы, планшетная раскладка (постоянная боковая панель от 840 dp).

## Примеры команд
«Открой youtube.com», «Открой настройки Wi-Fi», «Открой Telegram», «Который час?», «Пауза», «Следующий трек», «Позвони +380501234567», «Позвони Маша», «Отправь смс Маша Я скоро буду», «Запомни, что у меня аллергия на орехи».
Названия контактов ищутся по подстроке, без склонений («Маше» не найдёт «Маша»).

## Ограничения (честно)
- **Активация словом «Колд» не реализована.** Обычный `SpeechRecognizer` не подходит для постоянного прослушивания, а отдельная модель (например, Porcupine или Vosk) не подключена. Микрофон включается только кнопкой и выключается при сворачивании приложения.
- Облачной синхронизации нет, все данные хранятся на устройстве.
- Ключ Gemini хранится через `EncryptedSharedPreferences`; в исходниках ключа нет. Если шифрование недоступно на устройстве, ключ не сохраняется между запусками.
- Gemini сам ничего на телефоне не выполняет. Действия делает только локальный модуль команд.
- Качество распознавания и наличие украинского/русского голоса зависят от установленных на устройстве сервисов Google.
- Собирается только debug-APK (подписан отладочным ключом).

## Gemini API
1. Получите бесплатный ключ: https://aistudio.google.com/apikey
2. В приложении: Настройки → Gemini API → вставьте ключ, при необходимости смените модель (по умолчанию `gemini-2.5-flash`) → Сохранить.
Бесплатные лимиты определяет Google и они могут меняться.

## Gradle wrapper
В архиве нет `gradle-wrapper.jar` (его нельзя было скачать без сети), поэтому workflow запускает Gradle 8.7 через `gradle/actions/setup-gradle`, а не через `./gradlew`. Для сборки на GitHub это ничего не меняет.

## Как загрузить на GitHub с планшета и получить APK
Мобильный браузер не умеет загружать папки, поэтому проще всего так:
1. На github.com создайте новый репозиторий (Public или Private), ветка по умолчанию — `main`. Отметьте «Add a README file», чтобы ветка создалась.
2. Откройте репозиторий → **Add file → Upload files** → выберите **сам ZIP-архив** (не распаковывая) и нажмите **Commit changes**. Назовите его, например, `project.zip`.
3. Откройте **Code → Codespaces → Create codespace on main** (у GitHub есть бесплатный месячный лимит).
4. В терминале Codespace выполните:
   ```
   unzip -o project.zip && rm project.zip
   git add -A && git commit -m "COLD AI" && git push
   ```
5. Откройте вкладку **Actions**. Сборка запустится сама. Если нет: **Build COLD AI APK → Run workflow**.
6. Через несколько минут откройте завершённый запуск → внизу **Artifacts → COLD-AI-APK** → скачайте ZIP, распакуйте, установите `app-debug.apk` (разрешите установку из неизвестных источников).
7. Если сборка красная, откройте шаг с ошибкой и скопируйте текст.

Этот путь не проверялся на вашем устройстве: интерфейс GitHub может отличаться.
